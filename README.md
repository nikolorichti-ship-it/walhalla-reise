# Walhalla – Website für GitHub Pages

## Vorschau
Öffne `index.html` im Browser. Eine separate, vollständig eingebettete Vorschau-Datei befindet sich zusätzlich im Download. Bei der normalen Website müssen `index.html`, `style.css`, `script.js` und der gesamte Ordner `assets/` gemeinsam bleiben.

## Auf GitHub Pages veröffentlichen
1. Ein öffentliches GitHub-Repository erstellen (z. B. `walhalla-reise`).
2. **Den Inhalt dieses Ordners**, nicht den übergeordneten Ordner, in das Hauptverzeichnis des Repositories hochladen. Die MP4-Datei ist ca. 6,4 MB groß.
3. Unter **Settings → Pages → Build and deployment → Deploy from a branch** den Branch `main` und Ordner `/(root)` auswählen.
4. Nach der Veröffentlichung die angezeigte URL öffnen und Video auf dem Smartphone testen.
5. Erst dann einen QR-Code mit der fertigen URL erstellen.

## Video
Das fertig konvertierte Video ist als `assets/reisebuero.mp4` eingebaut. HTML5-Player mit Ton und Vollbild.

## Schriftarten
Fließtext: **Source Sans 3** (Google Fonts). Titel: CSS versucht zuerst lokal vorhandene **Trajan Pro** bzw. **Trajan Pro 3** zu verwenden. Auf Geräten ohne Trajan wird die ähnliche frei verfügbare Schrift **Cinzel** geladen. Für exakt Trajan Pro auf allen Geräten ist eine lizenzierte Adobe-Fonts-Webeinbindung (z. B. eigenes Adobe Fonts Web Project) notwendig. Es werden keine Trajan-Schriftdateien verteilt.

## Bilder
Zweiter Panoramastreifen ist die ältere Version mit 3 Motiven (ohne zusätzliches Wolkenfeld).

## Wissenschaftliche Quellen
Die Quellennachweise stammen aus dem eingereichten Druckfolder. Für eine vollständig zitierfähige Bibliografie müssen die konkreten Edda-Ausgaben/Übersetzungen und vollständige Angaben zum dort genannten Sekundärwerk noch nachgetragen werden.

## Datenschutz
Die Website verwendet Google Fonts, wodurch beim Online-Aufruf Fonts von Google geladen werden. Für eine datensparsame Offline-Lösung kann die Schrift mit entsprechend erlaubter Lizenz lokal eingebunden werden. Keine Cookies, keine Analytics.

## Kreatives Impressum
Der Abschnitt „Impressum der Ewigkeit“ ist eine ausdrücklich fiktive Reisebüro-Inszenierung. Bei einer öffentlichen Website ersetzt diese Gestaltung keine eventuell erforderlichen echten Anbieter-/Kontaktangaben. Diese müssten durch die verantwortliche Schule bzw. die Projektverantwortlichen geprüft und bei Bedarf ergänzt werden.
